# Code of Conduct

## Our pledge

We are committed to making participation in this project respectful and constructive for everyone.

## Expected behavior

- Be considerate and professional.
- Discuss technical issues in good faith.
- Accept constructive feedback.
- Focus on what is best for the project and its users.

## Unacceptable behavior

Harassment, discrimination, threats, personal attacks, deliberate disruption, and publishing someone else's private information are not acceptable.

## Enforcement

Report problems privately through the security contact described in [SECURITY.md](SECURITY.md). Project maintainers may remove comments, close discussions, or restrict participation when needed to keep the project safe and productive.
