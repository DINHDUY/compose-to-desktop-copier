# Security policy

## Reporting a vulnerability

Please do not report security vulnerabilities in a public issue. Email the repository owner through the contact method listed on the [GitHub profile](https://github.com/DINHDUY), including:

- a description of the vulnerability;
- the affected file, command, or workflow;
- steps to reproduce; and
- any suggested mitigation.

You will receive a response when the report has been reviewed. Please allow time for a fix before publicly disclosing the issue.

## Scope

This repository contains a Copier template and development workflows. Do not include real credentials, private container registry tokens, or production `.env` files in issues or pull requests.
